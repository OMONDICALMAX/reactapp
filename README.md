## React Project Management Dashboard

A simple **React + Vite** project management application that allows users to add, search, and view projects using a Bootstrap-styled UI.

## Features

-Add new projects
-Search projects by title
-View project list in card layout
-Track project status 
    Completed
    Pending
-Responsive Bootstrap UI
-Fast performance using Vite

## Tools Used

- React (Frontend library)
- Vite (Build tool)
- Bootstrap (Styling framework)
- JavaScript (Logic)

## Runing the App
1. Clone the repository
`` bash
   git clone https://github.com/calmaxomondi/reactapp.git
2. Navigate to the project by using this prompt
   cd reactapp/vite-project
3. Install dependancies by runing this prompt
   cd reactapp/vite-project
4. Run development server by runing this code
   cd reactapp/vite-project
5. Open the project in your browser using this link
   http://localhost:5173/
